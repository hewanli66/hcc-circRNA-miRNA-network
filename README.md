R 4.6.1) as the single source of truth. The misalignment did not affect the selection
of the 103 candidate circRNAs.

## Execution order

```
1.  step1_map_filter.py            differential circRNA screening, host gene mapping
2.  step2_tcga_survival.py         Cox / log-rank in TCGA-LIHC
3.  step3_validate14520.py         independent validation in GSE14520
4.  step4_immune.py                immune infiltration scoring and correlation
5.  step6_network.py               circRNA–miRNA–mRNA network assembly
6.  step7_miRNA_binding_v2.py      circBank retrieval, coordinate harmonisation, edges
7.  step8_network_qc.py            deduplication, quality scoring, tier assignment
8.  step9_nt5dc2_support.py        indirect support for NT5DC2
9.  step9b_fallback_support.py     indirect support for all fallback-matched genes
10. step11_backfill_binding.py     targeted re-retrieval of missed circBank entries
11. step12_immune_rebuild.py       two-cohort immune association rebuild
12. step14_export_for_R.py         export expression/clinical/survival matrices for R
13. step15_multivar_cox.R          multivariable Cox (survival::coxph, ties = "efron")
14. step16_cox_benchmark.R         agreement check against the Python implementation
15. step17_fdr_report.R            BH-FDR recheck across all 92,204 features
16. step18_major1_evidence.R       two-level evidence for candidate circRNAs

```

Steps 13–18 are written in R and were run under R 4.6.1.

## Environment

Python 3.13.12 for steps 1–12 and 19; R 4.6.1 for steps 13–18. Python steps use the
**standard library only** and require no third-party packages. Figure rendering
additionally requires `Pillow`; `make_submission_figures.py` uses a headless browser
to rasterise SVG.

## Three technical issues encountered and resolved

1. **Chromosome nomenclature mismatch.** GSE122482 uses `chrN:start-end` while circBank
   uses `N:start-end`. Without harmonisation only 33 of 103 candidates matched at exact
   coordinates (32%); after harmonisation 95 matched (92%) — exact 33, loose 18 and
   gene-fallback 44.
2. **Duplicate edges from pagination overlap.** The circBank binding interface returns
   overlapping records at pagination boundaries, producing 831 duplicate edges (5.1%)
   in the raw retrieval. Removed by composite key on (circRNA, host gene, miRNA, energy,
   score), leaving 15,479 unique edges.
3. **Incomplete retrieval.** The initial retrieval covered 1,925 of 2,448 result pages
   (79%) and missed five circRNA entries that declared miRNA predictions, including
   HSD17B6 and circADAMTS13. Targeted re-retrieval added 976 edges, after which the
   network grew from 14,568 to 15,479 edges, from 74 to 79 circRNAs and from 69 to 73
   host genes. All reported figures derive from the completed dataset.
